驱动级日志（TASK_BEGIN/DONE、block_start / early_end / block_end）。绿条 = block 执行区间，深绿段 = drain，竖线 = task 边界。交互：滚轮以光标为锚缩放、底部滚动条/小地图平移、悬停看数值、点击固定。

__NOTE__

block 执行 [block_start, block_end] drain [early_end, block_end] TASK_BEGIN TASK_DONE TASK_BEGIN（其它 stream）
口径：仿真 cycle。本视图为驱动级事件（无指令级 Push/RETIRE），与 issue-queue dump 的泳道图是两种粒度，不可直接互比。日志若在某个 task BEGIN 处截断，后续 block 事件不在文件内。
